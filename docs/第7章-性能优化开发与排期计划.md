## 1. 背景与目标

### 1.1 现状痛点

前端 Gradio → Gateway WebSocket → NATS JetStream → ASR Worker (faster-whisper) → NATS → Gateway/Storage/Refiner 全链路存在 6 类瓶颈：同步阻塞、Base64 膨胀 33%、固定 2s 硬切、单线程推理、同步落盘、LLM 同步调用，导致端到端延迟 2.5~3.5s、GPU 利用率 <20%、单点不可扩展。

### 1.2 优化目标（量化）

| 指标 | 现状 | P0 完成后 | P0+P1 完成后 | 测量方式 |
|------|------|-----------|--------------|----------|
| 端到端延迟 | 2.5~3.5s | 1.0~1.5s (-55%) | 0.8~1.2s (-65%) | `client_capture_ts` → 前端显示时间戳 |
| NATS 单消息带宽 | 85KB | 55KB (-35%) | 15KB (-82%, Opus) | `nats --jsz` + Prometheus `nats_bytes` |
| ASR Worker 吞吐 | 0.5 req/s/GPU | 1.5 req/s | 3.0 req/s | `asr_worker_inference_seconds` histogram |
| Storage 吞吐 | 2 msg/s | 10 msg/s | 20 msg/s | `storage_s3_upload_seconds` |
| 并发能力 | 1 Gateway 单点 | 2 副本 + QueueGroup | HPA 2~5 副本 | 10 并发客户端压测 |

### 1.3 约束

* 硬件：1× Jetson Orin Nano (sm_87, 8GB) + 1× Raspberry Pi 4B
* 兼容性：优化期间保持对外 WebSocket 协议兼容，NATS 需兼容 Base64 老消息（灰度期双读）
* 不影响 §1-§6 排期，独立分支 `perf/pipeline-opt`

## 5. 关键技术设计摘要

### 5.1 Gateway VAD 滑动窗口

```python
class VADChunker:
    def __init__(self, sample_rate=16000, min_chunk=0.8, max_chunk=1.5, overlap=0.3):
        self.vad = webrtcvad.Vad(2)
        self.buf = bytearray()
        self.overlap_bytes = int(overlap * sample_rate * 2)
    def feed(self, data: bytes) -> list[bytes]:
        self.buf.extend(data)
        if self._has_silence() or len(self.buf) >= max_chunk_bytes:
            chunk, self.buf = self.buf[:cut], self.buf[cut - self.overlap_bytes:]
            return [chunk]
        return []
```

### 5.2 二进制 NATS 负载

```python
# 发布
headers = {"req_id": req_id, "session_id": session_id, "ts": str(time.time())}
await js.publish("asr.input", pcm_bytes, headers=headers)
# 订阅
async def process_msg(msg):
    pcm = msg.data
    meta = msg.headers  # 无需 base64
```

灰度期兼容：`if "audio_b64" in data: pcm = b64decode(...) else: pcm = msg.data`

### 5.3 ASR 微批

```python
queue = asyncio.Queue()
sem = asyncio.Semaphore(2)
async def batch_loop():
    while True:
        batch = [await queue.get()]
        await asyncio.sleep(0.05)
        while not queue.empty() and len(batch) < 4:
            batch.append(queue.get_nowait())
        await asyncio.gather(*[infer_with_sem(b) for b in batch])
```
